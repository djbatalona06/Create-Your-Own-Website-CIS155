Featured: The Pregnancy Test

In 2020 a developer named Foone Turing gutted a digital pregnancy test, kept the tiny screen, and drove it with a microcontroller running DOOM. The original hardware only really supplied the display and the case, which started a long argument online about what counts as running DOOM. It is still the most famous one anybody has done, and it is the reason the whole challenge went mainstream.

What Counts as a Port?

People argue about this constantly. The strict answer is that the device's own processor has to run the game code. Under that rule the pregnancy test does not count, since a separate microcontroller does all the work and the test only supplies a screen. The looser answer is that if the pixels are coming out of a pregnancy test, then the pregnancy test runs DOOM. Nobody has settled it, which is probably why people keep trying.

I think the strict version is the more interesting one. It forces you to work inside a real limit: this exact chip, this much memory, this specific display controller. That is where the actual engineering happens, and it is why a calculator port gets more respect than a Raspberry Pi taped behind somebody else's screen.

Source Ports at a Glance

A "source port" is a modernized build of the game made from id's original 1997 source release. Every one of these still loads the same WAD files, just with different priorities.
