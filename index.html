About DOOM

DOOM is a first-person shooter released by id Software in December 1993. Built by programmers John Carmack and John Romero, it dropped players into a demon-infested Mars base armed with a shotgun and a chainsaw. It was fast, violent, and technically groundbreaking for its time, and it helped define an entire genre of video games.

More than thirty years later, DOOM is remembered for something almost as impressive as the game itself: it seems to run on anything. Because the original code was released to the public, hobbyists have spent decades porting it to hardware that was never meant to play games at all.

Unlikely Places DOOM Has Shown Up

"It runs DOOM" has become an internet challenge of its own. If a device has a processor and a screen — and sometimes even without a real screen — someone has probably gotten DOOM working on it. Here are some of the most surprising places it has shown up:

  • Graphing calculators used in math class
  • A digital pregnancy test
  • ATM machines and gas-station pumps
  • Smart refrigerators and washing machines
  • Digital cameras and printers
  • John Deere tractor dashboards
  • Tiny handheld "cyberdecks" built by hobbyists
